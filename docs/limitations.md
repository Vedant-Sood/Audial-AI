# Current limits

- Sign output is known-phrase ISL lookup with four included phrases. It is not full speech-to-ISL sentence translation. Light poses omit detailed facial grammar and require review by fluent signers.
- The sign classifier's 16/16 test result comes from a very small four-class clip-disjoint set. Signer independence is unverified, softmax scores are uncalibrated, and unknown signs may be assigned a known label.
- CREMA-D contains acted English speech with six actor-directed labels. Historical released WavLM results were 80.8% overall accuracy; accepted estimates reached 88.8% at 81.9% coverage. On the repeated actor-disjoint RAVDESS transfer check, WavLM reached 51.14% accuracy / 0.3994 macro-F1 versus 18.18% / 0.0514 for the acoustic baseline. This was previously exposed evaluation data, not a new blind test or newly trained model. Natural meetings and Indian-language accuracy remain unestablished. Estimates default to off and never change caption words.
- Pitch is an estimate of fundamental frequency; recorded level is dBFS, not real-world sound pressure or a measure of emotion. Noise, recording gain, speakers and unvoiced sounds affect measurements.
- Whisper recognition can omit or change words and punctuation. Speaker labels are session-only clusters. The basic ECAPA path uses VAD regions and cannot reliably resolve rapid changes inside continuous speech or simultaneous speakers.
- Browser shared audio and Document Picture-in-Picture depend on OS/browser support. An extension cannot read protected browser pages. System loopback uses the default playback output. Windows device capture, CUDA and executable packaging were not tested on the user's laptop.
- Chrome for Testing 156 and Edge Stable 155.0.4283.62 passed the full hosted Windows transport lifecycle on October 21, including suspend/restore. Edge 155 crashes when a tab is discarded while Playwright's debugger is attached (reproduced with a minimal tabs-only extension), so the Edge check detaches the debugger before discarding. On `main`, the installer workflow's Edge capture check now fails on Edge 156 ([run 39821972598](https://github.com/Vedant-Sood/Audial-AI/actions/runs/39821972598)); that is open. Physical laptop behavior is unverified.
- Queue limits protect memory and responsiveness. Slow inference or upload can drop audio with explicit warnings and preserved gaps. Export preserves completed captions, but cannot reconstruct speech that was never processed.
- Opening the companion requires a running local Audial-AI process. The packaged desktop starts it automatically and includes the runtime; end users do not install Python separately. The companion is not a remotely hosted inference service.
- Older benchmark files and experiment/ONNX artifacts are historical. The exact unpublished October 14 patch archive remains unavailable and is documented in [source recovery](source_recovery-0.5.0.md). This branch preserves the available public history and independent improvements; the missing five commits have not been merged.
